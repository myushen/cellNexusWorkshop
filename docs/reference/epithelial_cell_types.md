# Epithelial labels used for the expression analysis.

Epithelial labels used for the expression analysis.

## Usage

``` r
epithelial_cell_types()
```

## Value

A character vector of `cell_type_unified_ensemble` labels.

## Examples

``` r
epithelial_cell_types()
#> [1] "epithelial" "pneumocyte" "secretory" 
```
