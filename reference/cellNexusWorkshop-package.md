# cellNexusWorkshop: From the Human Cell Atlas to Analysis with cellNexus

Hands-on BiocAsia workshop. Participants query curated Human Cell Atlas
data with cellNexus, explore SingleCellExperiment objects with the
tidyomics packages, test cell-type composition with sccomp, and test
gene expression on donor-level pseudobulk.
